## Print for the table

Open a plan at **`/dm/plans/[slug]/`**, then **Print plan** (or **Cmd+P** / **Ctrl+P**).

Print CSS is scoped to session plans only: site chrome is hidden, A4 margins, dense black ink, clear table borders, and HP tick boxes under numeric HP cells for crossing off with a pen. Maps stay to a usable height so they do not eat five pages.

This is a practical run sheet from the markdown — not a full replacement for the illustrated PDF packs under `/dm/pdfs/`.

Assets: `/dm/maps/` · `/dm/pdfs/`. Full DM nav: **`/dm/`**.
