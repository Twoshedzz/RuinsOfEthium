# Session notes — after-play inbox (raw → novel)

**Session notes** (also called the **session log**) = **what happened at the table**. Raw after-play record used to author novel chapters.

| This folder is… | This folder is **not**… |
|-----------------|-------------------------|
| Session notes / session log | **Session plans** (prep) — [`../session-plans/`](../session-plans/) · [`../../table/`](../../table/) |
| Our table’s history for authoring | **Modules** (replayable) — [`../world/modules/`](../world/modules/) |
| The place for “Thorn did X / Nibbles fell” | Published novel prose — [`../../chapters/`](../../chapters/) |

**On the site:** `/dm/notes/` — session notes / campaign log.

---

## After the next game

1. Copy template or open the next folder:

```bash
cp -r publish/source/sessions/_template publish/source/sessions/session-XX
```

2. Fill **`what-happened.md`** — date, who played, scene bullets, combat, loot, decisions, quotes, loose ends  
3. Optional: long ChatGPT paste → `chatgpt-export.md` (keep raw)  
4. Point Cursor here when drafting the next chapter  
5. Prep **next** night with a **session plan** (`session-plans/` → `table/`) — do not put play-by-play in modules
