# Session plans (prep for an upcoming session)

**Session plans** = prep for *tonight*. Pull together stats, descriptions, maps, and trackers **before** you play.

Draft markdown lives here; the sheet you open at the table goes in [`../../table/`](../../table/) → **`/dm/plans/`**. Printable PDFs are canonical in [`../../table-assets/pdfs/`](../../table-assets/pdfs/).

| Term | Folder | Meaning |
|------|--------|---------|
| **Session plans** (this folder + `table/`) | Prep for an upcoming session |
| **Session notes** | [`../sessions/`](../sessions/) | What happened at the table → novel |
| **Modules** | [`../world/modules/`](../world/modules/) | Replayable building blocks |

Do **not** call this folder “session notes.”

## Naming

```
session-plan-01-….md
session-plan-05-….md
```

New plan from template: copy [`_template.md`](_template.md).
