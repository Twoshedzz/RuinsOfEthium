define the image.

## Reference wording example

```text
Reference 1 — role: creature anatomy only.
Use for: hunched torso, long ape-like arms, broad hands and shaggy fur.
Ignore: colour, lighting, background, pose, armour and digital rendering style.
```

When no single creature image is authoritative, assign separate jobs to several
references—for example body plan, head anatomy, surface texture and scale.
Never say only “combine these references”; state which features come from each.

External reference images may be attached directly or kept as working material
under `publish/source/inbox/monsters/`. Check usage rights before redistributing
an external image as part of a published product.
