# Chapter drafts (running order)

**Story pipeline** — not table prep and not world gazetteers. Beat sheets → published [`../../chapters/`](../../chapters/).

**Workflow for each new chapter:**

1. **Draft** — create `NN-slug.md` here: a short running order of scenes/beats (not finished prose).
2. **Annotate** — you add brief tabletop notes, quotes, loot, funny fails in the placeholders.
3. **Write** — ask Cursor to turn the draft into published chapter prose in [`../../chapters/`](../../chapters/) using [`style-guide.md`](../style-guide.md) and the campaign bible.
4. **Lock** — when the novel chapter is published, leave this draft as the historical beat sheet (optional: mark status `published`).

These files are **authoring source**, not site content. Do not sync into `src/content/`.
