# Adventure modules (replayable)

**Modules** = **replayability**. Building blocks so another DM (or you) can run the campaign again — possibly publishable later.

**Not** session notes (what happened). **Not** session plans (tonight’s prep).

**On the site:** `/dm/modules/` (DM hub — bookmark `/dm/`).

Each file: **overview → areas → encounters with stats → maps → loot / links**. Neutral DM framing (“If the party reaches…”, “Possible outcomes…”). Status: **`ready to run`**, not “played by our table.”

| Holds | Notes |
|------|--------|
| Description | Atmosphere, layout, room flow |
| Monster stats | From PDFs / trackers → `table-assets/pdfs/` → `/dm/pdfs/` |
| Maps | [`../maps/`](../maps/); phone via [`../../../table-assets/table-maps.manifest`](../../../table-assets/table-maps.manifest) |
| NPC hooks | Who can appear — not “our party already rescued them” |

**Do not put here:** party play-by-play. That goes in [`../../sessions/`](../../sessions/) (**session notes**).
