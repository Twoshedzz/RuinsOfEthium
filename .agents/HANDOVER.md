## Rules that bite if you don't know them

1. **`[skip netlify]` on every commit message.** Build credits cost money. Deploy
   deliberately — either `npm run deploy`, or omit the tag on a commit you intend
   to publish.
2. **Edit content only under `publish/`.** `src/content/` and parts of `public/`
   are generated by `scripts/sync-publish.mjs` on every build and your edits there
   are overwritten.
3. **Run `npm run verify` before pushing.** A pre-push hook runs it; GitHub Actions
   runs it again from a clean clone.
4. **Never `git add` a folder, and never `git add -A`, in Ethium Source.** Pete
   keeps deliberate uncommitted files under `publish/`. **Stage by name.** Right
   now that repo has untracked cover references, an `incoming/castle-maps/` folder
   and a modified `.hooks/pre-push` — all his, all to be left alone.
5. **Show visual work on localhost before deploying it.** Design is Pete's
   speciality and the part he can judge. Code and content can ship as normal.
6. **Pete is not technical.** He cannot review code or spot bugs — verification is
   always the agent's job, and he must never be asked to confirm a change is
   correct. He will spot visual and narrative problems instantly, and has
   repeatedly caught real faults that a glance missed and measurement would not have.
7. **Two tables, two aesthetics, and never the trademarks.** The kids' book takes
   the Basic red-box and Fighting Fantasy look; Tuesday Night Arguing takes the
   Advanced D&D look. Covers are Pete's own paintings in homage. Reference scans
   live in `publish/archive/` and reach no site.
8. **Session notes are a record only.** Dictated play notes go in the session file
   and `state.md` — never edit plans, modules or canon from them unless asked.

## Analytics — two systems, on purpose

| Site | Google Analytics | Cloudflare Web Analytics |
|---|---|---|
| Ruins of Ethium | `G-3CQ0WK6GZQ` | `e52688f1ce8a4fedaf456d4f2e829ee5` |
| Tuesday Night Arguing | `G-1X0V19M38G` | `89a688af0ecd47e487f9e4e8a6c742f2` |
| Ethium Source | none | none |

Both IDs and tokens are committed in each repo's `src/lib/site.ts`. **None of them
is a secret** — every one is served in the page source. `PUBLIC_GA_ID` and
`PUBLIC_CF_BEACON_TOKEN` override them.

- **Google Analytics** is behind Consent Mode v2, declared denied *before* gtag
  loads, with a consent bar. It therefore only ever counts readers who click Allow.
- **Cloudflare** is cookieless — it stores nothing on the device, so it needs no
  consent and counts everybody. No sessions, no returning visitors, no individuals.

**The two will never agree and Cloudflare will always be higher.** That gap is the
useful part: it shows what share of readers GA cannot see. Pete has not yet decided
which he treats as "the" number.

The reader's **cover choice and reading position** are also consent-gated: nothing
is stored unless they accepted, and withdrawing consent deletes it.

## Traps already paid for — don't rediscover these

- **Decap reserves the field name `body`.** It pulls `data.body` out as the file's
  markdown body and hands it to the frontmatter serialiser, which throws on a list.
  The chapter block list is called `blocks` for this reason. Renaming it back breaks
  saving entirely and silently, for the co-author.
- **A relative `og:image` is silently ignored by every unfurler.** It resolves fine
  in a browser, so the tags look right and the card stays blank. Always absolute.
  There is a `link-previews` skill covering the whole job — use it for any new site.
- **`100vw` includes the scrollbar**, so a full-bleed element using it is wider than
  the space available and scrolls the page sideways on every desktop.
- **`[hidden]` loses to a class setting `display: flex`** — equal specificity, later
  rule wins, attribute silently does nothing. Needs an explicit
  `.thing[hidden] { display: none !important }`.
- **Asserting that a property changed is not a test.** The consent bar's `hidden`
  property was `true` while the bar was still on screen. Measure what rendered —
  computed style, bounding boxes.
- **localStorage is per origin, and the port is part of it.** Testing on :4321 and
  :4323 gives two separate stores, which looks like a bug and isn't.
- **A local build passing is not evidence.** A Netlify deploy once failed on a file
  that was gitignored but present locally. `npm run verify` exists because of it.
- **Astro 5 caches content** in `node_modules/.astro`. If a content or plugin change
  appears not to apply, delete that directory.
- **The DM password lives only in Netlify's `DM_PASSWORD`.** Never put a passkey in
  a repo, and never use a `PUBLIC_`-prefixed variable for a secret — those are
  compiled into the browser bundle.
- **`EthiumSource/publish/archive/` is never synced.** It holds verbatim Wizards of
  the Coast text and scans of published books, kept as reference only. Confirm with
  `grep -c archive scripts/sync-publish.mjs` — the answer should stay 0.
- **Chained `verify && commit && push && deploy` in one Bash call gets refused** by
  the permission classifier. Run them as separate commands.
