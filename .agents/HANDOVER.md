## Rules that bite if you don't know them

These are in `AGENTS.md` too. They are repeated because breaking them costs real
money or real work.

1. **`[skip netlify]` on every commit message.** Build credits cost money. Deploy
   deliberately with `npm run deploy`. *(This was suspended for two 24-hour windows
   on 7–8 Oct and is back in force.)*
2. **Edit content only under `publish/`.** `src/content/` and parts of `public/`
   are generated by `scripts/sync-publish.mjs` on every build and your edits there
   are overwritten.
3. **Run `npm run verify` before pushing.** It builds, then checks commits, links,
   images, secrets, asset weight, filenames and per-repo content rules. A pre-push
   hook runs it; GitHub Actions runs it again from a clean clone.
4. **Never `git add` a folder or use `git add -A` in Ethium Source.** Pete keeps
   deliberate uncommitted files under `publish/`. Stage by name. There are
   currently several uncommitted cover reference images there — **leave them.**
5. **Show visual work on localhost before deploying it.** Design is Pete's
   speciality and the part he can actually judge. Code and content can ship as
   normal.
6. **Pete is not technical.** He cannot review code or spot bugs. Verification is
   always the agent's job — never ask him to confirm a change is correct. He will
   spot visual and narrative problems instantly, and has repeatedly caught things
   that measurement would have caught and a glance did not.

## Traps already paid for — don't rediscover these

- **Decap reserves the field name `body`.** It pulls `data.body` out as the file's
  markdown body and hands it to the frontmatter serialiser, which throws on a list.
  The chapter block list is called `blocks` for this reason. Renaming it back would
  break saving entirely, silently, for the co-author.
- **`100vw` includes the scrollbar.** Any full-bleed element using it is wider than
  the space available and scrolls the page sideways on every desktop. Break out of
  the page column instead of using viewport units.
- **`[hidden]` and a class setting `display: flex` have equal specificity**, so the
  attribute silently does nothing and the later rule wins. Any component relying on
  `hidden` needs an explicit `.thing[hidden] { display: none !important }`.
- **Asserting that a property changed is not a test.** The consent bar's `hidden`
  property was `true` while the bar was still on screen. Measure rendering —
  `getComputedStyle`, bounding boxes — not state.
- **localStorage is per origin, and the port is part of the origin.** Testing on
  :4321 and :4323 gives two separate stores, which looks like a bug and isn't.
- **A local build passing is not evidence.** A Netlify deploy once failed on a file
  that was gitignored but present locally. `npm run verify` exists because of it,
  and CI runs it from a clean clone.
- **Astro 5 caches content** in `node_modules/.astro`. If a content or plugin change
  appears not to apply, delete that directory.
- **The DM password lives only in Netlify's `DM_PASSWORD`.** Never put a passkey in
  a repo, and never use a `PUBLIC_`-prefixed variable for a secret — those are
  compiled into the browser bundle. `PUBLIC_GA_ID` is fine; a measurement ID is
  public by design.
- **`EthiumSource/publish/archive/` is never synced.** It holds verbatim Wizards of
  the Coast text and scans of published books, kept as reference only. Nothing in
  it may reach any site, including the password-walled one. Confirm with
  `grep -c archive scripts/sync-publish.mjs` — the answer should stay 0.
