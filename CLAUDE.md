# The Ruins of Ethium

**The full working agreement lives in [`.agents/AGENTS.md`](.agents/AGENTS.md). Read it before doing anything in this repo.**

That file is the single source of truth — it is kept in `.agents/` because Antigravity reads it from there. This root file exists so Claude Code and other tools that look in the repo root find it too. Put new rules in `.agents/AGENTS.md`, not here.

The rules most easily broken by an agent that has not read it yet:

1. **Append `[skip netlify]` to every commit message.** Build credits cost money. Deploy only when explicitly asked, with `npm run deploy`.
2. **Edit content only under `publish/`.** `src/content/chapters/` and `public/illustrations/` are generated by `scripts/sync-publish.mjs` and your edits there will be overwritten.
3. **Run `npm run verify` before pushing.** It builds and runs every pre-flight check. The user is not technical and cannot review code or spot bugs — never ask them to confirm that a change is correct.
4. **This repo is the novel only.** World canon, modules, maps, session plans and play records live in the private EthiumSource repo. Nothing here is secret; if a world fact needs changing, change it there.
