# The Ruins of Ethium

**The full working agreement lives in [`.agents/AGENTS.md`](.agents/AGENTS.md). Read it before doing anything in this repo.**

That file is the single source of truth for how to work here — it is kept in `.agents/` because Antigravity reads it from there. This root file exists so that Claude Code and other tools that look in the repo root find it too. Keep both in step: put new rules in `.agents/AGENTS.md`, not here.

The three rules most easily broken by an agent that has not read it yet:

1. **Append `[skip netlify]` to every commit message.** Netlify build credits cost money. Deploy only when explicitly asked, with `npm run deploy`.
2. **Edit content only under `publish/`.** `src/content/` and parts of `public/` are generated by `scripts/sync-publish.mjs` and your edits there will be overwritten.
3. **Verify your own work with `npm run build`.** The user is not technical and cannot review code or spot bugs — never ask them to confirm that a change is correct.
