# Choose-Your-Own-Adventure export

Branching reworking of *The Ruins of Ethium* for a single-player D&D-style game.  
**Separate from** the published novel in [chapters](../chapters/) — the novel stays linear; this folder is the game spine.

## Not in the novel nav

These files sync to the hidden site hub **`cyoa`** (`noindex`). Separate from the DM hub ([dm](/dm/)) and from published chapters.

| File | Purpose |
|------|---------|
| [`FORMAT.md`](/cyoa/format/) | Passage markup + how to import into a game engine |
| [`FLOW.md`](/cyoa/flow/) | Mermaid flow diagrams of all major choices |
| [`book-01-the-road-to-ethium.md`](/cyoa/book-01-the-road-to-ethium/) | Full CYOA covering prologue → Chapter 5 (pool camp) |
| [`encounters.md`](/cyoa/encounters/) | Combat encounter stubs (resolve with open D&D rules) |

Browse: **`cyoa`** after `npm run publish` / `npm run build`.


## Scope (Book 1)

North Road → goblin cave → Fallcrest / Blue Moon → Hammer manor → waterfall climb → Ethium plateau → ruined tower → Garnel → healing pool.

Open threads left for later books: east dig, castle hill, black dragon, Maelis Varn, Mala’s book, cloaked watcher.

## Player role

Second person. **You are Thorn Axehand** (half-orc fighter). Your companions — Derek, Dave, Nibbles, Loki — travel with you unless a passage says otherwise. Choices are yours; companions react in the prose.

## Tone

Same as the novel: Fighting Fantasy for ~12+, warm, clear, silly-but-earnest. Combat is exciting but not graphic.

## Not published as novel chapters

These files are a **CYOA reader** on the site at `cyoa` (hidden URL). They are not novel chapters under `chapters`.
