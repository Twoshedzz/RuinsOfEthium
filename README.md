# The Ruins of Ethium

A static novel site built with [Astro](https://astro.build), styled after classic
Fighting Fantasy books — parchment pages, serif type, and black-and-white illustration
plates. Hosted on [Netlify](https://www.netlify.com).

**What this is:** the published story of a family D&D campaign, for the boys, parents
and friends to read after each session.

```bash
npm install
npm run dev      # http://localhost:4321
```

## The three apps

| App | Repo | What it is |
|---|---|---|
| **Ruins of Ethium** | this one | The kids' novel, public |
| **Tuesday Night Arguing** | [`TuesdayNightArguing`](https://github.com/Twoshedzz/TuesdayNightArguing) | The same campaign run for an adult group, public |
| **Ethium Source** | `EthiumSource` (private) | World canon, modules, maps, and both tables' prep and records |

**The DM material left this repo in October 2026.** World notes, replayable modules,
tactical maps, PDFs, session plans and play records are all in Ethium Source, behind a
password. Nothing in this repo is secret: it is a novel and the pictures in it.

Old `/dm/` links redirect to the cover.

## Writing a chapter

Everything is authored under `publish/`. `src/content/chapters/` and
`public/illustrations/` are generated by `scripts/sync-publish.mjs` on every `dev` and
`build`, and edits there are overwritten.

```bash
cp publish/chapters/_template.md publish/chapters/08-your-slug.md
```

The numeric prefix orders the chapters and the filename becomes the URL.

```yaml
---
title: "The Road to Fallcrest"
chapter: 1
summary: "One sentence describing what happens in this chapter."
coverIllustration: "/illustrations/scenes/ch01-cover.png"
published: true
---
```

| Field | Required | Notes |
|-------|----------|-------|
| `title` | Yes | Shown on the page |
| `chapter` | Yes | Orders the book; `0` is the Prologue |
| `summary` | No | Blurb for the chapter list |
| `coverIllustration` | No | Path under `/illustrations/` |
| `published` | Yes | `false` keeps a draft off the site |

Prose style lives in [`publish/source/style-guide.md`](publish/source/style-guide.md).

## Before you deploy

```bash
npm run verify
```

One command, plain English. It builds, then checks that everything the build needs is
committed, that no links or images are broken, that no secrets or DM material have crept
in, and that assets are a sensible size. A pre-push hook runs it automatically; GitHub
Actions runs it again from a clean clone.

| Command | Does |
|---|---|
| `npm run dev` | Sync + dev server |
| `npm run build` | Sync + production build |
| `npm run verify` | Build + all pre-flight checks |
| `npm run publish` | Sync only |
| `npm run deploy` | One deliberate Netlify build |

**Append `[skip netlify]` to every commit message.** Build credits cost money. Deploy
only when you mean to.

## Shared with the other book

This app shares its layout and components with Tuesday Night Arguing — same chapter
reader, same navigation, different skin. A fix to the reader here is worth applying
there; there is no shared package, so it has to be done by hand, and that is deliberate.
